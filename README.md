### 🧹 [Excel Data Cleaning Tool](https://github.com/Punsala-Dhananjanee/excel-cleaner)
> Automates the most painful part of data work — cleaning messy Excel files

- Removes duplicate rows automatically
- Fills missing values using smart strategies (median, mode)
- Standardizes column names and fixes data types
- Exports a clean file + a full cleaning report
- Supports any Excel file including real business and Kaggle datasets

```bash
python main.py your_data.xlsx
```
